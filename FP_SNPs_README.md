# Конвертация SNP-файла в формат REF/ALT

## Введение

Скрипт `convert_snp.py` предназначен для преобразования файла со списком SNP из формата GRAF:

| #CHROM |   POS   |    ID     | allele1 | allele2 |
| ------ | ------- | --------- | ------- | ------- |
|  chr1  | 1220751 | rs2887286 |    C    |    T    |
|  chr1  | 1275912 | rs6685064 |    T    |    C    |

в формат, совместимый с VCF-подобным представлением: 

| #CHROM |   POS   |    ID     | REF | ALT |
| ------ | ------- | --------- | --- | --- |
|  chr1  | 1220751 | rs2887286 |  T  |  C  |
|  chr1  | 1275912 | rs6685064 |  C  |  T  |

Для каждой позиции скрипт обращается к референсному геному ***GRCh38*** (через `pysam.Fastafile`), определяет, какой из двух аллелей совпадает с референсом (**REF**), а какой является альтернативным (**ALT**), и записывает результат в выходной TSV-файл.

## Начало работы

### Требования

- Python 3
- Библиотека `pysam` (устанавливается в Docker при сборке командой `pip3 install pysam`)
- Референсный геном GRCh38, разбитый на отдельные хромосомы (`chr1.fa`, `chr2.fa`, …, `chrX.fa`, `chrY.fa`) с индексами `.fai`.
  Референс не входит в репозиторий и должен быть подготовлен отдельно (см. раздел «Подготовка референса»).

### Скачивание референсного генома

Референсный геном **GRCh38** не входит в Docker-образ и не хранится в репозитории. Его нужно скачать и подготовить отдельно.

Официальный источник:

- **GDC Reference Files**: https://gdc.cancer.gov/about-data/data-harmonization-and-generation/gdc-reference-files
- Прямая ссылка на архив: `https://ftp-trace.ncbi.nlm.nih.gov/ReferenceSamples/seqc/Somatic_Mutation_WG/technical/reference_genome/GRCh38/GRCh38.d1.vd1.fa.tar.gz`

После скачивания распаковать архив:

```bash
tar -xzf GRCh38.d1.vd1.fa.tar.gz
```

### Подготовка референса

Внутри Docker-контейнера или в среде с `samtools`:

```bash
# Извлечь хромосомы из общего FASTA и проиндексировать
for i in {1..22} M X Y; do
  samtools faidx GRCh38.d1.vd1.fa chr$i > ref/sepChrs/chr$i.fa
  samtools faidx ref/sepChrs/chr$i.fa
done
```

В результате в папке `ref/sepChrs/` появятся файлы `chr1.fa`, `chr1.fa.fai`, `chr2.fa`, `chr2.fa.fai` и т.д.

### Подготовка входного файла (FP_SNPs.txt)

Исходный файл `FP_SNPs.txt` из архива GRAF 2.4 содержит 6 колонок и включает SNP на X-хромосоме (хромосома 23):

|   rs#   | chromosome | GB37_position | GB38_position | allele1 | allele2 |
| ------- | ---------- | ------------- | ------------- | ------- | ------- |
| 2887286 |     1      |    1156131    |    1220751    |    C    |    T    |
| 6685064 |     1      |    1211292    |    1275912    |    T    |    C    |


Для приведения к формату, ожидаемому скриптом, используется команда `awk`:

```bash
awk 'BEGIN{OFS="\t"} \
     NR==1 {print "#CHROM","POS","ID","allele1","allele2"; next} \
     $2 != "23" {print "chr"$2,$4,"rs"$1,$5,$6}' \
     data/FP_SNPs.txt > data/FP_SNPs_10k_GB38_twoAllelsFormat.tsv
```

#### Комментарии к команде

- `BEGIN{OFS="\t"}` — устанавливает табуляцию как разделитель полей.
- `NR==1 {print "#CHROM","POS","ID","allele1","allele2"; next}` — заменяет исходный заголовок на ожидаемый и переходит к следующей строке.
- `$2 != "23"` — исключает строки, относящиеся к X-хромосоме (в исходном файле она обозначена номером 23).
- `print "chr"$2, $4, "rs"$1, $5, $6` — формирует новые колонки:
    - `chr` + номер хромосомы (колонка 2);
    - позиция GRCh38 (колонка 4);
    - `rs` + идентификатор SNP (колонка 1);
    - аллель 1 (колонка 5);
    - аллель 2 (колонка 6).

Результат сохраняется в `data/FP_SNPs_10k_GB38_twoAllelsFormat.tsv`. В файле остаётся 10 000 SNP (X-хромосома исключена).

## Запуск

Запуск скрипта (пример внутри Docker-контейнера, рабочая директория `/workspace`):

```bash
python3 convert_snp.py \
  --input data/FP_SNPs_10k_GB38_twoAllelsFormat.tsv \
  --output data/FP_SNPs_10k_GB38_REF_ALT.tsv \
  --ref /ref/GRCh38.d1.vd1_mainChr/sepChrs/ \
  2> data/log.txt
```

## Опции

```
-h, --help                  show this help message and exit
--input INPUT, -i INPUT     Путь к входному файлу
--output OUTPUT, -o OUTPUT  Путь к выходному файлу
--ref REF, -r REF           Путь к папке с референсными FASTA-файлами
```

Справка по аргументам вызывается командой:

```bash
python3 convert_snp.py -h
```

## Вход

- **Входной файл** (`--input`): TSV-файл с заголовком `#CHROM POS ID allele1 allele2`.
- **Референс** (`--ref`): папка, содержащая FASTA-файлы хромосом (`chr1.fa`, …, `chrY.fa`) и соответствующие индексы `.fai`.

Скрипт проверяет заголовок входного файла и завершается с ошибкой, если формат не соответствует ожидаемому. Ошибки открытия файлов также обрабатываются и логируются.

## Выход

- **Выходной файл** (`--output`): TSV-файл с заголовком `#CHROM POS ID REF ALT`.
- **Лог** (`2> data/log.txt`): сообщения с временными метками о ходе работы, предупреждения и итоговая статистика.
